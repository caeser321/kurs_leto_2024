# Анкета клиента с подписью стилусом

Клиент заполняет анкету, расписывается стилусом прямо на экране планшета
и получает готовый PDF.

Есть две сборки из одного и того же кода:

| Сборка | Что это | Где хранятся анкеты |
| ------ | ------- | ------------------- |
| **[Android-приложение](app/README.md)** | APK, который заказчик ставит на планшет. Работает без сервера и без интернета. | В памяти планшета, выгрузка через «Поделиться» |
| **Веб-версия** (этот каталог) | Сайт на сервере в локальной сети, планшеты открывают его в браузере. | В общей папке на сервере |

Описание анкеты, проверки, поле для подписи и генератор PDF — общие:
правка `forms/anketa.json` меняет обе сборки сразу.

**Нужен APK — смотрите [app/README.md](app/README.md).** Ниже описана
веб-версия.

## Что умеет

- **Анкета в браузере.** Поля описаны в JSON, форма строится автоматически.
  Интерфейс рассчитан на планшет: крупные поля, никакого масштабирования при вводе.
- **Подпись стилусом.** Учитывается сила нажатия пера: чем сильнее нажим,
  тем толще линия. Пока клиент расписывается, случайные касания ладонью
  игнорируются. Есть отмена последнего штриха и полная очистка.
- **PDF на выходе.** Документ собирается на сервере: данные анкеты,
  тексты согласий и изображение подписи. Кириллический шрифт встраивается
  в файл, поэтому документ одинаково открывается на любом компьютере.
- **Общее пространство.** Готовые PDF складываются в настраиваемый каталог
  и сразу доступны через веб-архив с поиском.

## Запуск

```bash
cd client-forms
npm install
npm start
```

Приложение поднимется на <http://localhost:3000>:

- `/` — анкета для клиента;
- `/archive` — архив сохранённых анкет.

Чтобы клиенты открывали анкету с планшетов, запустите сервер на компьютере
в той же сети и дайте им адрес вида `http://192.168.1.50:3000`.

## Настройка

Все параметры задаются переменными окружения:

| Переменная   | По умолчанию          | Назначение                                  |
| ------------ | --------------------- | ------------------------------------------- |
| `PORT`       | `3000`                | Порт веб-сервера                            |
| `HOST`       | `0.0.0.0`             | Интерфейс, на котором слушать               |
| `SHARED_DIR` | `client-forms/shared` | **Общее пространство** для готовых PDF      |
| `FORM_FILE`  | `forms/anketa.json`   | Файл с описанием анкеты                     |

### Общее пространство

`SHARED_DIR` — это обычный каталог, поэтому подойдёт любой способ,
которым в организации уже расшарены файлы:

```bash
# сетевой диск (SMB/NFS), примонтированный в систему
SHARED_DIR=/mnt/office-share/anketa npm start

# каталог, который синхронизируется Nextcloud, Яндекс.Диском или Google Drive
SHARED_DIR="$HOME/Nextcloud/Анкеты" npm start
```

Файлы раскладываются по годам и месяцам, рядом с каждым PDF лежит JSON
с теми же данными в машиночитаемом виде:

```
shared/2026/08/20260816-143022-K3F9QA__ivanov-petr-sergeevich.pdf
shared/2026/08/20260816-143022-K3F9QA__ivanov-petr-sergeevich.json
```

Кириллица в именах файлов транслитерируется — сетевые шары нередко портят
не-ASCII имена. Запись идёт через временный файл с последующим
переименованием, поэтому клиент синхронизации никогда не подхватит
наполовину записанный PDF.

Отдельной базы данных нет намеренно: архив строится обходом каталога,
поэтому он остаётся рабочим, даже если файлы попали туда с другой машины.

## Как изменить анкету

Поля описаны в [`forms/anketa.json`](forms/anketa.json) — править код не нужно,
достаточно перезапустить сервер.

```json
{
  "name": "phone",
  "label": "Телефон",
  "type": "tel",
  "required": true,
  "maxLength": 30,
  "pattern": "^[0-9+()\\-\\s]{6,30}$",
  "hint": "Цифры, пробелы и символы + ( ) -"
}
```

Доступные типы: `text`, `textarea`, `date`, `tel`, `email`, `number`,
`select`, `radio`, `checkbox`. Для `select` и `radio` нужен список `options`,
для `checkbox` метка становится текстом согласия и печатается в PDF целиком.

Правила `required`, `maxLength`, `pattern` и списки допустимых значений
проверяются и в браузере, и повторно на сервере — данные из формы
не принимаются на веру.

## Проверки

```bash
npm test
```

Тесты покрывают разбор анкеты и валидацию, раскладку и перенос текста в PDF,
встраивание кириллического шрифта, сохранение в общее пространство
(включая защиту от выхода за пределы каталога) и HTTP-API целиком.

## Устройство

Общие модули — работают и на сервере, и внутри Android-приложения:

```
src/schema.js          проверка анкеты и значений, форматирование
src/pdf.js             сборка PDF: макет, перенос текста, блок подписи
src/naming.js          имена файлов и номера документов
forms/anketa.json      описание анкеты
fonts/                 DejaVu Sans — шрифт с кириллицей для PDF
public/js/signature-pad.js  поле для подписи (Pointer Events, нажим пера)
public/js/form-ui.js   построение формы по описанию, подсветка ошибок
```

Только для веб-версии:

```
server.js              точка входа
src/config.js          настройки и поиск шрифтов
src/app.js             HTTP-API и раздача статики
src/storage.js         запись и чтение общего пространства
src/form-file.node.js  чтение описания анкеты с диска
src/fonts.node.js      чтение шрифтов с диска
public/js/app.js       отправка анкеты на сервер
```

Только для приложения — `app/` (см. [app/README.md](app/README.md)).

Модули `pdf.js` и `schema.js` намеренно не обращаются к файловой системе:
шрифты и описание анкеты передаются в них готовыми данными. Благодаря
этому один и тот же генератор PDF работает и на сервере, и на планшете.

### HTTP-API

| Метод и путь                    | Назначение                             |
| ------------------------------- | -------------------------------------- |
| `GET /api/form`                 | Описание анкеты                        |
| `POST /api/submissions`         | Приём анкеты, создание и запись PDF    |
| `GET /api/submissions`          | Список сохранённых анкет (`?search=`)  |
| `GET /api/submissions/:id/pdf`  | Готовый PDF (`?download=1` — скачать)  |
| `GET /api/health`               | Состояние сервиса                      |

## О подписи

Поле подписи работает на Pointer Events, поэтому одинаково понимает перо,
палец и мышь. Точки хранятся в нормализованных координатах — подпись
не искажается при повороте планшета. В PDF уходит PNG с прозрачным фоном,
обрезанный по краям росчерка и отрисованный в тройном разрешении.

Если стилус не поддерживает нажим (или клиент расписывается пальцем),
толщина линии считается по скорости движения — быстрый росчерк тоньше.

## Персональные данные

Заполненные анкеты содержат персональные данные, поэтому каталог `shared/`
исключён из репозитория. Перед боевым использованием стоит закрыть архив
аутентификацией и вынести приложение за HTTPS-прокси — сейчас доступ
к `/archive` открыт всем, кто видит сервер по сети.
